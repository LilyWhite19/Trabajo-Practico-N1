# Tienda de VideoJuegos: STARPOINT

Esta es una pagina web con un cátalogo de videojuegos de diversar compañias, el proyecto esta construido a base de "React-Bootstrap" y esta simulada sobre una base de datos creada con JavaScript

## Instalacion para funcionamiento

Las librerias que se utilizaron fueron: react, bootstrap, react-bootstrap, react-router-dom

Importante instalar todas las librerias para el correcto funcionamiento del la pagina
